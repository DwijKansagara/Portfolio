Cookie Policy

This page explains browser storage and third-party connections used by this portfolio.

1. Current cookie use

The portfolio application does not set advertising, analytics, social-media, or personalisation cookies. It does not use a cookie-based visitor counter or behavioural profile.

2. Essential local storage

StoragePurposeDuration
theme in browser local storageRemembers whether you selected the light or dark theme.Until you change it or clear site data.
Browser cache or model cacheIf you explicitly enable the optional on-device assistant, the browser may cache model and runtime files so they do not need to be downloaded every time.Controlled by your browser. You can remove it by clearing site data.
Temporary page memoryHolds terminal history and assistant messages while the page is open.Cleared when the page is reloaded or closed.

3. Third-party requests

No analytics or social embed is loaded automatically. The hosting provider receives the normal request needed to deliver the page. Hugging Face and GitHub receive network requests if you explicitly enable the optional assistant. GitHub, Instagram, and other linked sites receive requests after you follow their links.

4. Is a cookie consent banner required?

For the site's current configuration, no optional cookie consent banner is shown because the application does not set non-essential cookies or load analytics, advertising, or third-party embeds automatically. The theme value is a user-requested display preference. If optional tracking, advertising, or embedded third-party media is added later, it must remain blocked until the required consent mechanism is implemented.

5. Your controls

You can use browser settings to inspect or clear cookies, local storage, cache storage, and site permissions. Clearing site data resets the saved theme and may remove downloaded assistant files. Blocking storage may prevent preferences from being remembered but should not prevent basic portfolio browsing.

6. Contact

Questions about storage can be sent to kansagara.dwij@gmail.com. Related processing information appears in the Privacy Policy.
